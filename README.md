# Lab Task 06 - Abstract Data Types (ADT)

## Objective

The objective of this lab is to implement simple Abstract Data Types (ADTs) in Java, use interfaces to define contracts, and apply abstraction and encapsulation principles.

## Tasks Completed

### Task 1 - Stack ADT
Implemented an ArrayStack using the LIFO principle. Tested push and pop operations with values 10, 20, and 30.

### Task 2 - Data Encapsulation
Created a Student class with private fields for ID, name, and CGPA. Public getter methods are used to access the private data.

### Task 3 - Programming to an Abstraction
Used the List interface with both ArrayList and LinkedList implementations.

### Task 4 - Library System ADT
Created a LibrarySystem interface and LibraryImplementation class with operations to add, remove, search, issue, and return books.

### Task 5 - Student Management System
Created StudentCollection interface and its implementation. JUnit tests were written for adding, finding, removing students, checking size, and checking whether the collection is empty.

## How to Run

1. Open the project in NetBeans.
2. Build the Maven project.
3. Run the required Java test classes.
4. Run StudentCollectionTest as a JUnit test.
